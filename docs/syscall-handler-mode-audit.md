# Syscall mode audit

Audit of the production handlers before the mode correction in this change. All 82 production descriptors were declared `async`; none awaited or otherwise suspended in its handler. The 70 public descriptors wrapped synchronous implementation functions, while the 12 private net descriptors immediately returned `-ENOSYS`. Public implementation functions may themselves park through the established syscall-continuation mechanism; that does not make their CRTP handler asynchronous. The correction changes all 82 handlers to `sync` and keeps actual task/suspension behavior covered by generic framework tests.
