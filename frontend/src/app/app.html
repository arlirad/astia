Freestanding x86_64 · C++20

An operating system built to be understood.

Astia is a small, freestanding hobby OS for learning, experimentation, and systems programming on QEMU. It pairs a typed C++20 kernel with native userspace, loadable device modules, and a deliberately bounded feature set.
